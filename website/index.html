What you get

Everything you expect from an everyday browser, plus an assistant that can read and work with web pages.

Tabs your way

Tab groups, vertical tabs, split view, workspaces and sleeping tabs that save memory.

AI chat

Ask questions about the current page, summarize articles or translate them. Bring your own API key or run a local model.

Agent mode

Describe a task and watch Pelagic browse, click and fill in forms. Passwords are never shown to the AI.

Built-in privacy

Ad blocking, a password manager with breach checks and warnings for unsafe sites.

Familiar tools

Bookmarks, history, downloads, reader mode, screenshots, picture-in-picture and spell check.

Your homepage

Shortcuts, a search box and a background you choose.

Installing

Takes about a minute. No account needed.

Windows
  1. Download

    Click the Windows download button and save PelagicSetup-1.0.0.0.exe.

  2. Run the installer

    If Windows shows "Windows protected your PC", click More info then Run anyway. This appears because the installer isn't code-signed yet.

  3. Open Pelagic

    Find it in the Start menu or on your desktop. To use AI features, add an API key in Settings.

Linux
  1. Download and unpack

    Save Pelagic-1.0.0-linux-x86_64.tar.gz, then run tar xzf Pelagic-1.0.0-linux-x86_64.tar.gz.

  2. Install

    In the unpacked folder run ./install.sh. It installs into ~/.local without sudo. ./install.sh --remove uninstalls.

  3. Open Pelagic

    Find it in your applications menu. Saved passwords and API keys are protected by your system keyring (GNOME Keyring, KWallet or KeePassXC).
